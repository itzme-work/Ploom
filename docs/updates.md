Stable исключает prerelease. Beta включает предварительные версии. Ручная и добровольная стартовая проверки читают опубликованные релизы. При сетевой ошибке состояние актуальности неизвестно.

На доверенном компьютере с JDK, Bash и установленными npm-зависимостями запустите scripts/setup-signing.sh из корня. Мастер интерактивно создаёт постоянные ключи вне Git. Сохраните пароли в менеджере паролей и сделайте зашифрованную автономную копию каталога. Утрата Android-ключа для прямой дистрибуции препятствует выпуску совместимого обновления.

Для будущего выпуска создайте защищённое GitHub Environment release с проверяющим владельцем. Вводите ключи только через Settings → Environments → release → Environment secrets. Для Tauri используйте TAURI_SIGNING_PRIVATE_KEY и TAURI_SIGNING_PRIVATE_KEY_PASSWORD. В исходниках допустим только публичный ключ. Официальный выпуск пока заблокирован до реализации и проверки обоих установщиков.

## Native Completion
Windows принимает адрес установщика только из официального релиза. Максимальный объём 256 МиБ, перед запуском проверяются подпись Tauri и подписанная версия. Сборка для распространения должна получить PLOOM_UPDATER_PUBLIC_KEY при компиляции. Отсутствующий ключ блокирует установку.

Android прямой дистрибуции ожидает Ploom-arm64.apk под тегом v<версия>. После tauri android init выполняется python3 android/prepare.py. Адаптер проверяет APK Signature Scheme v2/v3, сертификаты текущей установки, package name, versionName и возрастающий versionCode. Ротация сертификата пока требует отдельного процесса. Для Play-дистрибуции следует выпускать отдельный manifest без REQUEST_INSTALL_PACKAGES. Debug APK разных CI-запусков может иметь разные тестовые сертификаты. Для проверки обновления с сохранением данных нужны две сборки с одной доверенной подписью.

Порядок приёмки и подготовки закрытого тестового стенда приведён в [репетиции обновления](update-rehearsal.md). Перед выпуском заполните [чек-лист устройств](device-validation.md) для Android ARM64 и Windows x64 и приложите результаты перехода между подписанными версиями.
