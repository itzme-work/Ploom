Stable исключает prerelease. Beta включает предварительные версии. Ручная и добровольная стартовая проверки читают опубликованные релизы. При сетевой ошибке состояние актуальности неизвестно.

На доверенном компьютере с JDK, Bash и установленными npm-зависимостями запустите scripts/setup-signing.sh из корня. Мастер интерактивно создаёт постоянные ключи вне Git. Сохраните пароли в менеджере паролей и сделайте зашифрованную автономную копию каталога. Утрата Android-ключа для прямой дистрибуции препятствует выпуску совместимого обновления.

Для будущего выпуска создайте защищённое GitHub Environment release с проверяющим владельцем. Вводите ключи только через Settings → Environments → release → Environment secrets. Для Tauri используйте TAURI_SIGNING_PRIVATE_KEY и TAURI_SIGNING_PRIVATE_KEY_PASSWORD. В исходниках допустим только публичный ключ. Официальный выпуск пока заблокирован до реализации и проверки обоих установщиков.
