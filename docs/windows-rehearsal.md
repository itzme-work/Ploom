# Репетиция на Windows x64

**Пять действий владельца** от первой настройки до проверки. Счёт относится к этапам, внутри них есть подтверждения. Нужны Windows PowerShell 5.1 (встроен), GitHub CLI на ПК и Tailscale на ПК и Android. GitHub CLI передаёт секреты через зашифрованный API и загружает закрытые артефакты. Tailscale Serve предоставляет один HTTPS-адрес обоим устройствам внутри личного tailnet. Для личной лаборатории подходит бесплатный план Personal. На телефоне нужен Android ARM64 версии 9 или новее для прямого обновления.

1. **Подготовьте устройства.** На Windows установите GitHub CLI и Tailscale с официальных сайтов или командами `winget install --id GitHub.cli -e` и `winget install --id Tailscale.Tailscale -e`. Откройте новый PowerShell, выполните `gh auth login --hostname github.com`, пройдите вход в браузере. Войдите в один личный tailnet на ПК и телефоне. В DNS-настройках Tailscale включите MagicDNS и HTTPS Certificates. Используйте выделенный ПК без работающего Funnel/Serve, с зашифрованным диском. [GitHub CLI](https://cli.github.com/) · [Tailscale Serve](https://tailscale.com/kb/1242/tailscale-serve)
2. **Сделайте закрытую копию.** На GitHub нажмите **+ → Import repository**. Source URL — `https://github.com/itzme-work/Ploom.git`, Owner — личный аккаунт, Name — `Ploom-rehearsal`, Visibility — **Private**, затем **Begin import**. Дождитесь завершения. Проверьте ветку native-completion и отсутствие посторонних с правом записи. В Actions включите workflows, если GitHub предложит это сделать. Из проверенной ветки native-completion скачайте **Code → Download ZIP** и распакуйте. Если Windows блокирует скачанные скрипты, после проверки источника откройте **Свойства ZIP → Разблокировать** и распакуйте заново. Git устанавливать не требуется.
3. **Запустите настройку.** В корне распакованного проекта выполните `.\scripts\windows\Rehearse.ps1`. Мастер сверит коммит приватной ветки, покажет адрес стенда и попросит подтвердить репозиторий. Введите два отдельных надёжных пароля — для Tauri и Android. Пароли храните в менеджере. Скопируйте каталог `%LOCALAPPDATA%\PloomRehearsal\keys` на зашифрованный резервный носитель, проверьте читаемость копии и подтвердите BACKUP. Мастер попросит повторить пароли для GitHub Secrets и запустит матрицу сборок. Постоянные ключи создаются один раз на ПК. Секреты передаются только в подтверждённую закрытую копию. При неполном комплекте восстановите каталог из резервной копии. Для повторной настройки используйте тот же каталог.
4. **Запустите стенд.** Откройте **Private Ploom-rehearsal → Actions → Signed test packages → запуск**. Дождитесь зелёных задач матрицы и stage. В PowerShell выполните `.\scripts\windows\Rehearse.ps1 -Mode Download` и вставьте номер запуска из URL после `/runs/`. Мастер скачает проверенные артефакты в `%LOCALAPPDATA%\PloomRehearsal\run-НОМЕР` и включит закрытую раздачу. Оставьте окно открытым. Если Tailscale впервые предложит разрешить Serve через браузер, подтвердите это для личного tailnet. Для возобновления после остановки используйте `.\scripts\windows\Serve.ps1 -Directory "$env:LOCALAPPDATA\PloomRehearsal\run-НОМЕР\private-rehearsal-site"`.
5. **Пройдите обновление.** Установите 0.1.0 из каталогов rehearsal-0.1.0-Windows и rehearsal-0.1.0-Linux (во втором — APK, передайте его на телефон по USB или Taildrop). Выберите Beta, запомните язык, стиль и акцент. Нажмите проверку обновлений, затем обновление. На Android проверьте отмену, повторите и подтвердите системный диалог. После перезапуска проверьте 0.1.1-test и сохранённые значения на обеих ОС. Выполните отрицательные проверки по протоколу. Остановите стенд Ctrl+C. Если окно было принудительно закрыто, выполните `tailscale serve --https=443 off`. После приёмки можно удалить каталог run-НОМЕР, сохранив keys и его резервную копию. [Протокол приёмки](update-rehearsal.md#протокол-приёмки-на-каждой-ос)

**Одна переносимая утилита** cargo-tauri для Windows x64 загружается мастером из официального релиза. До исполнения проверяется фиксированный SHA-256. Каталог загрузки удаляется в finally. Для Android используется системная криптография Windows с экспортом в защищённый паролем PKCS#12. Временный сертификат и его ключ удаляются из CurrentUser после экспорта. При аварийном выключении проверьте каталог tools-* и сертификат Ploom Android Rehearsal через certmgr.msc перед повтором.

**Опционально:** менеджер паролей и зашифрованный резервный носитель можно выбрать самостоятельно. WSL, Git, Node.js, Rust, JDK, Android SDK, Python и Android Studio для этого пути устанавливать не нужно. Подпись, проверка сертификатов, выравнивания ARM64, версий и генерация метаданных выполняются в существующем закрытом GitHub Actions workflow. Используются ресурсы GitHub Actions личного аккаунта, включая квоту Windows runners.
