React отображает единый интерфейс. Zustand хранит только разрешённые значения настроек в версионируемой записи. packages/shared содержит контракты серверов, подписок, движка и защищённого хранилища. Rust запускает WebView. Движок версии 0.1 отказывает в подготовке соединения. Для реального подключения потребуются отдельные адаптеры ОС.

В версии 0.2.0 модуль subscriptions разделяет сетевую загрузку и диагностику (Rust), выделение и нормализацию записей (parser в Web Worker), сверку версий подписки (library), транзакционное хранение (vault) и координацию обновлений (manager). Презентационный слой читает локальное состояние Zustand. Исходное представление записи остаётся в зашифрованной библиотеке для экспорта и будущего адаптера движка.
