# Выбор сетевого ядра для следующего этапа

В 0.2.0 клиент выделяет из конфигурации конечные точки и хранит параметры. Ни один из рассматриваемых движков в сборку не включён. Для оценки ниже важна конкретная версия исходников: ветки и наборы параметров меняются.

| Кандидат | Форматы и протоколы, существенные для Ploom | Android и Windows | Лицензия и интеграция |
|---|---|---|---|
| Xray-core | Нативный Xray JSON, VLESS, VMess, Trojan, Shadowsocks, SOCKS, HTTP и WireGuard. Для данных Clash и sing-box требуется преобразование. | На Android приложение управляет согласием пользователя, жизненным циклом VpnService и передачей файлового дескриптора. На Windows нужно проверить поддерживаемый TUN-путь выбранной версии или отдельно интегрировать TUN-мост. | MPL-2.0. При распространении изменений в покрытых файлах действуют требования к исходникам этих файлов. Хороший кандидат для сценариев с транспортами Xray. |
| sing-box | Собственный JSON; VLESS, VMess, Trojan, Shadowsocks, Hysteria2, TUIC и WireGuard. Формат WireGuard endpoint зависит от версии. | Эталонный Android-клиент использует платформенную обвязку; TUN inbound поддерживает Windows. Потребуются защита исходящих сокетов от зацикливания, настройка маршрутов и корректное восстановление сети. | GPL-3.0-or-later. Перед включением библиотеки или бинарника проверить условия распространения всей поставки и зависимостей. |
| Mihomo | Нативные YAML-профили Clash/Mihomo, группы и правила, широкий набор прокси, включая Hysteria2 и TUIC. | На обеих платформах потребуется нативный жизненный цикл. TUN и маршрутизация требуют платформенных привилегий, которые клиент 0.2.0 не запрашивает. | Проверенная ветка **Meta** содержит GPL-3.0. Метаданные лицензии ветки по умолчанию отличаются; закрепить проверенный тег и проверить все лицензии конкретного бинарника. |

Ссылки на исходники и документацию: [Xray-core](https://github.com/XTLS/Xray-core) · [Xray outbounds](https://xtls.github.io/en/config/outbound.html) · [sing-box outbounds](https://sing-box.sagernet.org/configuration/outbound/) · [sing-box TUN](https://sing-box.sagernet.org/configuration/inbound/tun/) · [лицензия sing-box](https://github.com/SagerNet/sing-box/blob/testing/LICENSE) · [Mihomo proxies](https://wiki.metacubex.one/en/config/proxies/) · [лицензия ветки Meta](https://github.com/MetaCubeX/mihomo/blob/Meta/LICENSE).

Сравнимых замеров CPU, памяти, батареи и размера пакета на Redmi и Windows пока нет. Для выбора в 0.3.0 следует собрать одинаковые ARM64/x64 профили, прогнать один трафик через один тестовый сервер и снять RSS, CPU, скорость, расход батареи, продолжительность запуска и переключения сетей. Измерить отдельно маршрутизацию, DNS, TCP и UDP. Лицензирование, возможность воспроизводимой сборки и обновления ядра проверяются для того же тега. Решение о движке остаётся открытым.
