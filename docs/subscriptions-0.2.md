# Подписки Ploom 0.2.0

В разделе «Подписки» введите HTTPS-адрес в поле ссылки либо вставьте конфигурации в текстовое поле. Адрес HTTP/HTTPS-прокси вводится в текстовое поле. Доступны вставка из буфера, выбор файла и распознавание QR **из изображения**. Камера и соответствующее разрешение не используются. Открытие ссылки вида `ploom://import?url=<percent-encoded-https-url>` заполняет форму. Запрос к провайдеру начинается при предварительном просмотре.

Предпросмотр показывает формат, протоколы, корректные строки, ошибки и дубликаты. Можно снять выделение со всех и отметить нужные серверы. Текстовое поле подходит для обычных и Base64-списков, ссылок VLESS, VMess, Trojan, Shadowsocks (включая SIP002), SOCKS5, HTTP/HTTPS, Hysteria2 и TUIC. WireGuard INI разбирается по Peer с Endpoint. Для JSON читаются конечные точки Xray и sing-box, для YAML — коллекция proxies. Группы, правила маршрутизации, скрипты Clash и параметры сетевых ядер не применяются. Сохраняется исходная конфигурация выделенной записи; непредставленные глобальные настройки документа в неё не включаются. Внешние references, ключевые файлы и цепочки провайдеров автоматически не загружаются. [SIP002](https://shadowsocks.org/doc/sip002.html) · [WireGuard](https://www.wireguard.com/quickstart/).

«Подписки» позволяет переименовать источник, изменить URL, выбрать расписание и обновить одну подписку или все включённые. Ошибка сети, пустой ответ или повреждённые записи при обновлении оставляют прежний снимок. Данные трафика в байтах и дата окончания читаются из subscription-userinfo, сайт — из profile-web-page-url. Наличие метаданных зависит от провайдера. Автоматическое обновление работает при активном приложении, в том числе при возврате в окно. Служба Android для фоновой работы не создаётся.

В разделе «Серверы» выберите конфигурацию для главного экрана, выполните поиск, задайте фильтры, сортировку и избранное. Локальная копия хранится отдельно от источника. Для диагностики выполняется DNS-разрешение и измеряется время установления TCP-соединения. Доступность VPN, аутентификацию прокси и качество туннеля этот замер не проверяет. Для известных UDP-транспортов тест пропускается. Отмена останавливает очередь, уже начатые проверки ограничены заданным таймаутом.

Для переноса библиотеки раскройте «Резервная копия», задайте отдельный пароль и сохраните файл. Утерянный пароль копии восстановить невозможно. Восстановление заменяет библиотеку после расшифровки и подтверждения пользователем. Экспорт отдельных или выбранных конфигураций создаёт открытый файл после предупреждения. В настройках можно экспортировать отдельно предпочтения интерфейса. В Windows и Android сохранение вызывает системный выбор файла.

## Хранение и границы безопасности

Настройки интерфейса сохраняют прежний формат ploom.preferences. Библиотека версии 1 шифруется AES-256-GCM, новый IV и соль создаются при каждой записи. Пароль резервной копии обрабатывается PBKDF2-SHA256 с 600000 итераций. Для библиотеки на Android случайный секрет обёрнут ключом Android Keystore, на Windows используется DPAPI текущего пользователя. В IndexedDB хранится зашифрованный снимок; сравнение ревизии и замена выполняются в одной транзакции. Несовместимая версия или ошибка расшифровки блокирует чтение. В браузерном стенде для библиотеки используется пароль от 12 символов.

Нативный загрузчик ограничивает ввод 4 МиБ, таймаутом и пределом переходов. Для каждого перехода проверяются HTTPS и сохранение origin, все DNS-адреса проверяются до соединения и передаются HTTP-клиенту явно. Системный proxy отключён для этого запроса. Локальные и зарезервированные назначения блокируются; ручное исключение для LAN в этой версии не предусмотрено. Сертификат проверяется по публичным корневым сертификатам. URI, тело ответа и строки конфигурации не выводятся в сообщения об ошибках. Код из содержимого не исполняется. Копирование в системный буфер выводит секрет за пределы хранилища.

Парсер и криптографические операции выполняются в отдельных Web Workers. Ограничения парсера — 12000 записей, глубина JSON/YAML до 48, запрет YAML aliases и явных тегов; разбор прерывается через 15 секунд. Страница списка показывает до 80 карточек. При отсутствии однозначного совпадения сервер получает новый идентификатор. Сохранение алиаса при произвольной смене всех идентифицирующих параметров провайдера гарантировать нельзя.

## Измерения

Один запуск Node 24.22.3 на облачном Linux-хосте, отдельный процесс на каждый размер, синтетические Trojan URI. Измерены разбор и создание записей. Heap delta — изменение занятой JS-кучи, RSS — максимум процесса вместе с Node и библиотеками. Шифрование, сеть, отображение и сборка мусора в методику не включены. Повторение: `node scripts/benchmark-subscriptions.mjs`.

Физический Redmi Pad SE и ручная Windows-проверка отложены. Замеры на этих устройствах, совместимость с конкретными провайдерами и подключение через сетевое ядро не подтверждены.
