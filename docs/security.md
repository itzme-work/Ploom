Основные угрозы — утечка подписки, подмена пакета и откат версии. Форма подписки не отправляет и не сохраняет значения. Проверка релизов обращается к фиксированному API GitHub с отключёнными credentials и редиректами. Описание релиза выводится текстом. Установка артефактов пока недоступна. До выпуска нужны тесты подмены подписи, архитектуры, идентификатора и версии на каждой платформе.
