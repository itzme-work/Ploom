# Безопасность Ploom 0.2.0

Подписка может содержать пароль, персональный URL или приватный ключ WireGuard. Предпросмотр хранит входные данные в памяти. При подтверждении клиент записывает выбранные записи в зашифрованную локальную библиотеку. Перед копированием или открытым экспортом интерфейс запрашивает подтверждение. Буфер обмена, созданный открытый файл и доступ к уже разблокированной сессии находятся за пределами защиты библиотеки.

Загрузка подписки идёт к указанному пользователем HTTPS-источнику. Нативный клиент проверяет сертификат, допустимость адресов и origin перенаправлений. Парсер ограничивает объём, глубину и количество записей. Данные подписки не получают доступа к командам Tauri или настройкам приложения. Сетевые проверки используют только адреса импортированных серверов. [Границы реализации и хранение](subscriptions-0.2.md)

Проверка версии приложения использует официальный репозиторий. Android проверяет подлинность APK, идентификатор и возрастание версии перед передачей системному установщику. Windows проверяет подпись обновления Tauri. Секреты для подписания доступны защищённому процессу выпуска. [Обновления](updates.md) · [Выпуск через GitHub](browser-release.md)
