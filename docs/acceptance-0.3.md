### Подтверждение отключения и повторного подключения

На коммите 8ea2e11 установленные приложения в эмуляторах API 33, 35 и 36 прошли по две HTTP-сессии. В каждой прошёл запрос с одноразовым значением через контролируемый прокси. После отключения тест проверил исчезновение TUN из ConnectivityService, отсутствие записи службы PloomVpnService и отдельный прямой HTTP-запрос в интернет. Последующие сценарии Shadowsocks и REALITY в этих же заданиях завершались ошибками и требуют собственного положительного результата. [Android 13](https://github.com/itzme-work/Ploom/actions/runs/45739101820/job/139647543957) · [Android 15](https://github.com/itzme-work/Ploom/actions/runs/45739101820/job/139647544054) · [Android 16](https://github.com/itzme-work/Ploom/actions/runs/45739101820/job/139647544051)

В расширенной матрице API 24 и 26 проверяются VPN и обновление через системный установщик с одноразовыми тестовыми подписями. Проверка ARMv7 под трансляцией на Android 11 отдельно требует ABI armeabi-v7a, процесса app_process32 и прохождения двух HTTP-сессий. Положительный результат под трансляцией не измеряет производительность физического ARMv7-устройства.
